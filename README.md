# Extensão IFTO Palmas

Extensão para o Firefox (depois também para o Chrome) que melhora o SEI do IFTO e apoia o Sistema de Gestão Orçamentária do Campus Palmas.

Licença GPL-3.0 (`LICENSE`). Partes do código vêm do **SEI++** (Jonatas Evaristo, https://github.com/jonatasrs/sei, GPL-3.0); o **SEI Pro** (https://github.com/SEI-Pro/sei-pro, AGPL-3.0) é usado como referência, e trechos aproveitados dele mantêm a licença de origem, indicada no próprio arquivo.
