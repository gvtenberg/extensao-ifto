# Regras gerais da extensão

Decidido em 25/10/2026.

## Navegadores e instalação

- Primeiro o **Firefox**; depois o **Chrome**.
- Por enquanto, só no navegador do usuário, para testes: **instalação temporária** (`about:debugging#/runtime/this-firefox` > Carregar extensão temporária…), que some quando o Firefox fecha.
- Para instalar de vez: assinatura **não listada** da Mozilla (grátis, não aparece na loja). Pedida pelo usuário em 12/11/2026: feita **no GitHub**, para instalar no computador do trabalho sem passar pelo de desenvolvimento (`../publicacao.md`).

## Login e dados

- **Com login** na extensão (conta Google @ifto.edu.br): a extensão lê os dados **direto da Planilha Google** do sistema (a mesma planilha oficial; abas e colunas em `../sistema-orcamento-ifto/docs/planilha.md`).
- **Sem login:** funcionam só as melhorias do SEI.
- Sem custos: nada de serviços pagos (como no sistema).
- Nunca gravar nada num sistema oficial (SEI, planilha, SIAFI…) sem o usuário ver e confirmar antes.
