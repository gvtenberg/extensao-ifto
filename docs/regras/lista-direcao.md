# List of documents for the director to sign

Feature for the Director-General's office (v0.35.0, 23/11/2026): the chief of staff builds in the SEI the list sent to the director by WhatsApp; the director's panel (`lista-assinaturas.md`) reads it. Plan in `specs/lista-para-direcao.md`; code in `comum/lista-direcao.js` and `sites/sei/lista-direcao*.js`.

- **Who:** everyone in `PAL/REI/IFTO`, only there (setting `listaDirecao`, on by default). Kept only in the browser: keys `listaDirecao` (open list) and `listaDirecaoEnviadas` (sent lists), never mixed with `listaAssinaturas`.
- **Menu of the document icon:** "Adicionar à lista da direção" when the document's tree actions have "Assinar Documento" (own unit or received in a block); otherwise "Adicionar só para ciência" (comment always has "ciência"); both with "Adicionar vários deste processo" (signable documents, tree order, tick boxes). Items put in when the menu opens; documents in closed folders: the tree is read again with "Abrir todas as Pastas" (read only).
- **Warnings before adding:** already signed by whoever is signing now (full name in the tree's `ASSINATURA` action); already in a sent list. Already in the open list: not added again.
- **Document number:** end of the tree name, with or without parentheses ("Despacho 163 (3229092)", "Ateste Fatura Materiais 3375110").
- **Copied text:** one line per process, `processo - doc, doc comentário`; a different comment starts another line, keeping the list order. A comment that would be read as another document gets "obs.: " in front. A comment with the word "ciência" makes the item "só para ciência", as in the director's panel.
- **Panel:** the extension window (`sicaf-janela.js`), opened by the bar button "Lista para a direção (N)" and after adding. "Já enviei, começar outra" keeps the list in "Listas enviadas" (copy again). Old sent lists are deleted only with `direcaoApagar` on (term in `direcaoApagarDias`).
- **Who is signing:** director, or the substitute inside the period (end date required and included; blank start = already). Typed in the settings or chosen in "Escolher quem assina" (names from the SEI's assignment list; only the chosen people are kept).
- **Automatic assignment (`direcaoAtribuir`, off by default):** only when the logged-in matrícula is the recorded chief's, and only to whoever is signing. The click that adds the document is the confirmation. Already assigned to that person: nothing is sent. With the chief or nobody: assigns. With anyone else: asks; "no" keeps the item as "não atribuído" and is not asked again (only with "Tentar de novo"). One assignment per process. After sending, the page is read again and only then shows "Atribuído a".
- **Failure:** the item stays, in red, with the reason and "Tentar de novo"; copying lists those processes and asks. `hdnIdProtocolo` must be the open process.
- **Undo:** the previous person (SEI internal id and name, never the login, which is the CPF for contractors) is kept; removing the process's last item offers "Voltar a atribuição para <nome>" or "Retirar a atribuição". Never by itself; if someone else changed it meanwhile, asks. Retry and undo need the process open (the panel offers to open it).
- **Copy of the settings (file):** includes the recorded names and matrículas.
