# Commands: details

- `npm test` (rules in `testes/*.test.js`, Node runner; create a test for each new rule in `comum/`) · `npm run conferir` (Mozilla check, `web-ext lint --self-hosted`; at the end of each stage) · `npm run empacotar` (package in `web-ext-artifacts/`, outside git) · `npm run empacotar-chrome` (Chrome/Edge folder and `.zip` `extensao-ifto-chrome-edge-X.Y.Z` in `web-ext-artifacts/chrome/`; Firefox file in Releases: `extensao-ifto-firefox-X.Y.Z.xpi`, v0.18.1) · `npm run rodar` (test Firefox, clean profile without passwords) · `npm run rodar-sei` (19/11/2026: **the user's way to test before the merge**: separate test Firefox opening the SEI, profile kept in `ferramentas-de-teste/perfil-firefox-teste/` (outside git; password saving turned on there, 19/11/2026: the SEI password is typed once and saved only in that profile), extension reloads by itself when a file is saved; spell check in pt-BR (system dictionary `/usr/share/hunspell`); close that Firefox window or Ctrl+C in the terminal to stop).
- Temporary install (only for the everyday Firefox; the "Recarregar" button exists only for temporary installs): `about:debugging#/runtime/this-firefox` > **Carregar extensão temporária…** > `manifest.json` from the `extensao-ifto` folder. It disappears when Firefox closes; after changing code, **Recarregar** there.
- GitHub (`.github/workflows/assinar.yml`): on each pull request and merge it checks (`npm test`, `npm run conferir`); on master, if the `manifest.json` version is new, it signs with Mozilla (unlisted) and publishes the `.xpi`, the Chrome `.zip` and `updates.json` in Releases. Step by step in `docs/publicacao.md`. Dependabot (25/11/2026, `.github/dependabot.yml`): monthly pull requests, never merged by themselves; run `npm test` and `npm run conferir` first (they do not sign).
