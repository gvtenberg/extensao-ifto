# Version history (summary)

One or two lines per version, with the date (dd/mm/yyyy). Number 0.STAGE.FIX.

- v0.8.0 (12/11/2026): payment documents, stage 3: the button creates Sicaf, Consulta and Anexo (blank, today's date, Nato-digital, Público) after one confirmation, warning first when the extension already did it today or the tree has one of them without a file.
- v0.7.0 (12/11/2026): payment documents, stage 2: extension bar at the top right (signature list button moved there); "Incluir Sicaf, Consulta e Anexo" button with a process open (CGOC by default; creation comes in stage 3); settings page split into general and per unit.
- v0.6.0 (12/11/2026): payment documents, stage 1: new external document page comes with today's date, Nato-digital and Público (setting on by default; existing documents untouched); "Novo documento" button removed (SEI 5 always shows Incluir Documento).
- v0.5.0 (12/11/2026): signature list: "Assinar e próximo" (signs with the password Firefox already filled in and opens the next item) and "Dar ciência e próximo"; Chrome/Edge package (`npm run empacotar-chrome`, PNG icons, `.zip` in each Release); tip to show only the SEI password (`publicacao.md`). Docs switched to English.
- v0.4.2 (12/11/2026): "Instalar a versão…" opens the version page on GitHub (Firefox did not show the install prompt when the file was opened directly, and does not let the extension request an update); the message explains clicking the file and the Firefox menu path (Check for updates).
- v0.4.1 (12/11/2026): extension texts reviewed for the people who use it (the icon window no longer mentions GitHub, Actions or pushing code); rule recorded in `padrao-visual.md` and CLAUDE.md.
- v0.4.0 (12/11/2026): signature list, stage 3: "Assinar" and "Dar ciência" buttons in the panel, which click the SEI's own button (password and confirmation stay with the user). Improvement finished.
- v0.3.0 (12/11/2026): signature list, stage 2: "Feito e próximo" and done counter, clickable full list, acknowledgement items in blue, minimize, Alt+→ and Alt+← shortcuts, settings option (Automática / Sempre ligada / Desligada).
- v0.2.0 (12/11/2026): signature list in the SEI, stage 1: paste the list (process, document, comment; several formats), unrecognized lines in red, movable panel to the right of the button bar with Previous/Next and counter, opens each item via quick search; Director-General's office only (PAL/REI/IFTO). The extension now acts only on `sei.ifto.edu.br`.
- (12/11/2026, no version change) `TESTES-PENDENTES.md` compact, only as the source of the cards (read and delete scripts). Tests as GitHub cards (issues), with "Passou"/"Falhou" and comments; Claude's general rules copied to `docs/claude-regras-gerais.md` and checked at the start of each session.
- v0.1.3 (12/11/2026): "Procurar atualização" button in the icon window (checks the latest GitHub Release and installs with one click); GitHub checks the extension on every push; organization matching the main system (CLAUDE.md, commands, permissions).
- v0.1.2 (12/11/2026): automatic update in Firefox via GitHub (`update_url` + `updates.json` in each Release; public repository).
- v0.1.1 (12/11/2026): SEI 5 – password recognized by Firefox on the login page and when signing documents (the SEI started hiding the password in a text field); Mozilla signing via GitHub (`.github/workflows/assinar.yml`).
- v0.1.0 (26/10/2026): extension skeleton (Firefox 128+, Manifest V3, GPL-3.0 license): icon window with the recognized SEI (version and address), settings page, "Novo documento" button always visible in the process action bar (from SEI++); commands `npm test`, `npm run conferir`, `npm run empacotar`.
- (25/10/2026) Project created: CLAUDE.md, commands (`/planejar`, `/etapa`, `/testes`), `docs/` and `TESTES-PENDENTES.md` following the budget management system model; old SEI++ packaged for testing (outside git). No code yet.
