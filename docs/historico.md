# Version history (summary)

One or two lines per version, with the date (dd/mm/yyyy). Number 0.STAGE.FIX.

- v0.17.1 (13/11/2026): icon window: "Procurar atualização" and the link below it removed (did not work for the user); only the button "Abrir a página da versão mais nova", which opens the latest version page (also in Chrome).
- v0.17.0 (13/11/2026): Simples Nacional lookup, stage 1: reads the "Consulta Optantes" result page (`comum/simples-nacional.js`) and makes the extension's own searchable text PDF (`comum/pdf-texto.js`, A4, Helvetica, accents); file and tree names; head-office CNPJ of a branch (`cnpjMatriz`); `nomeNaArvore` (50 letters) moved to `comum/sei.js`. Nothing visible to users yet.
- v0.16.0 (13/11/2026): SICAF, two decisions of 13/11/2026: (1) with "Automática" the selected-CNPJ button and menu work only in the CGOC (other units need "Sempre ligada"); (2) blank Sicaf, Consulta and Anexo after the last Folha (made by "Incluir Sicaf, Consulta e Anexo", no tree name yet) are filled through "Alterar Documento Externo" (Sicaf: PDF + name; Anexo: name; Consulta: left as is) instead of creating new ones.
- v0.15.0 (13/11/2026): automatic SICAF, stage 6: with "Sempre ligada", "Incluir SICAF" button in any unit with a process open (type or paste the CNPJ; outside the CGOC only the Sicaf with the PDF). Spec closed: rules in `regras/sicaf.md`; README updated (feature, setting, permission, data read, pdf.js credit).
- v0.14.0 (13/11/2026): automatic SICAF, stage 5: confirmation window per supplier (PDF link, red warnings need a second click) and inclusion in the SEI without screens: Sicaf with the PDF ("Nome na Árvore" = SICAF company name), Consulta, and one Anexo per invoice ("Instrumento de Cobrança NF nº …"); names cut at 50 letters (SEI limit). Creation code shared in `sites/sei/sei-pedidos.js` (`incluirExternos`, also used by "Incluir Sicaf, Consulta e Anexo").
- v0.13.0 (13/11/2026): automatic SICAF, stage 4: "Buscar no SICAF" opens a SICAF tab (optional permission for Compras.gov.br and Downloads, asked once from the settings), helps with the gov.br login (Governo card highlighted; never logs in by itself), searches each CNPJ, catches the "Situação do Fornecedor" PDF, saves it in Downloads, keeps today's PDFs and brings them back to the SEI tab (CNPJ inside the PDF checked).
- v0.12.0 (13/11/2026): automatic SICAF, stage 3: "Buscar" reads each pending invoice PDF (supplier CNPJ = first valid non-IFTO CNPJ) and compares it with the ateste (buyer must be Campus Palmas; CNPJ, number, value and empenho in red; company name in yellow); red needs "Continuar mesmo assim"; scanned invoice or different CNPJ: pick or type the CNPJ.
- v0.11.0 (13/11/2026): automatic SICAF, stage 2: selecting a CNPJ on an SEI page shows a "Buscar SICAF" button; right-click menu "Buscar SICAF deste CNPJ" (also in the browser PDF viewer); window with a CNPJ field (paste or type, check digits). For now it only shows the CNPJ found. New background script `fundo/fundo.js` (Chrome: service worker).
- v0.10.0 (13/11/2026): automatic SICAF, stage 1: "SICAF da nota fiscal" option in the settings; in the CGOC, with a process open, the bar shows "N notas sem SICAF – Buscar" (invoices after the last Folha de Encaminhamento whose supplier, by the ateste CNPJ, has no Sicaf with that CNPJ in its PDF). PDF text read with pdf.js 6.4.299 (`bibliotecas/pdfjs/`). SEI request helpers moved to `sites/sei/sei-pedidos.js`.
- v0.9.7 (13/11/2026): icon window: "Procurar atualização" now only offers "Abrir a página da versão" (the direct install link did not work); README updated.
- v0.9.6 (13/11/2026): signature list reads several documents on one line ("processo - 3384598, 3384645, 3384674", also ";", "e" or spaces; repeated numbers count once).
